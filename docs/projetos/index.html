O grupo OctopusCode desenvolveu uma plataforma gamificada baseada em jogos de RPG e Rogue-like, com o objetivo de ensinar Scrum de forma divertida e interativa.

2DSM – 2º Sem. 2026

Projeto GreenEr - Grupo Let:zApplin

O premiado projeto GreenER é uma aplicação desenvolvida em equipe no Projeto de Aprendizagem Baseada em Problemas da FATEC.

A plataforma reúne indicadores de consumo energético e emissões estimadas de CO₂e, permitindo acompanhar serviços digitais, comparar seu impacto e simular cenários em diferentes regiões.

Minha atuação se concentrou no desenvolvimento e refinamento do frontend com React, TypeScript e CSS, com foco em responsividade e experiência mobile. Trabalhei na adaptação de dashboards, gráficos, rankings e controles para telas menores, preservando a leitura dos dados e das escalas. Também ajustei a interação por toque, o mapa de serviços, os painéis de detalhes, os popups e a visualização em tela cheia.

Participei da integração de funcionalidades, versionamento com Git e validação da aplicação em ambiente Docker. O projeto fortaleceu minha experiência em transformar requisitos em interfaces funcionais, investigar problemas de usabilidade e colaborar na evolução de uma aplicação orientada a dados e sustentabilidade.

Este projeto foi premiado com a melhor apresentação da Feira de Tecnologia da FATEC - 2º semestre.

Tecnologias utilizadas:

  • React
  • CSS
  • TypeScript
  • Node.js
  • PostgreSQL
  • Docker
  • MapLibre
  • Recharts
  • Git
